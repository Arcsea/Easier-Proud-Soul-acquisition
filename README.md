# Easier Proud Soul Acquisition / 简易耀魂获取

为 Minecraft 拔刀剑 SlashBlade: Resharped 增加种植获取耀魂的方式。

- 破坏草、高草或蕨，默认有 10% 概率掉落耀魂种子，可通过配置调整。
- 将种子种植在耕地上，成熟后收获耀魂与种子。
- `1.20.1/`：Forge，Java 17。
- `1.21.1/`：NeoForge，Java 21。
